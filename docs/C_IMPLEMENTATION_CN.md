# eviltransform C 实现详细说明

本文介绍 `c/transform.c` 中 WGS84 与 GCJ-02 转换的具体实现细节。

## 1. 文件结构

C 实现主要包含以下函数：

- `outOfChina()`：判断坐标是否位于 GCJ-02 适用区域。
- `transform()`：计算基础经纬度扰动量。
- `delta()`：完成扰动量的椭球修正。
- `wgs2gcj()`：WGS84 转 GCJ-02。
- `gcj2wgs()`：GCJ-02 快速逆转换。
- `gcj2wgs_exact()`：GCJ-02 高精度逆转换。
- `distance()`：计算两点球面距离。

## 2. WGS84 到 GCJ-02

转换流程：

```
WGS84 经纬度
    |
    | outOfChina 判断
    |
    | transform 计算扰动
    |
    | delta 椭球修正
    v
GCJ-02 经纬度
```

核心形式：

```
gcjLat = wgsLat + dLat
gcjLng = wgsLng + dLng
```

## 3. 扰动函数 transform()

算法首先将坐标平移：

```
x = longitude - 105
y = latitude  - 35
```

然后通过多项式和周期函数计算纬度、经度扰动：

- 多项式项
- sin 周期项
- sqrt(|x|) 项

这些扰动项用于模拟 GCJ-02 的非线性偏移。

## 4. 椭球修正 delta()

GCJ-02 不是简单的经纬度平移，因此需要根据地球椭球参数修正：

- 长半轴 EARTH_R
- 第一偏心率平方 ee

修正后的结果转换为角度偏移：

```
dLat
 dLng
```

## 5. 快速逆转换 gcj2wgs()

快速方法假设局部区域内偏移变化较小：

```
WGS ≈ GCJ - delta(GCJ)
```

优点：

- 速度快
- 适合普通地图应用

缺点：

- 存在米级误差

## 6. 高精度逆转换 gcj2wgs_exact()

高精度版本采用二分搜索：

```
猜测 WGS84
      |
      v
WGS84 -> GCJ02
      |
      v
计算误差
      |
      v
缩小搜索范围
      |
      v
重复直到收敛
```

停止条件：

- GCJ 纬度误差低于阈值
- GCJ 经度误差低于阈值
- 最大迭代次数 30 次

该方法比快速逆转换精度更高，但计算量更大。

## 7. 精度说明

GCJ-02 本身不是公开测绘参考框架，而是互联网地图坐标体系。

因此：

- 适合地图显示
- 不适合作为 RTK、PPP、高精度误差分析坐标

GNSS 工程建议：

```
内部计算：WGS84 / CGCS2000

地图显示：WGS84 -> GCJ-02
```

## 8. C 实现维护建议

修改转换公式时，需要同时关注：

1. 中国区域判断范围。
2. 椭球参数变化。
3. 正向转换与逆转换一致性。
4. 不同实现之间的兼容性。

GCJ-02 没有公开官方数学规范，当前实现属于社区长期验证形成的事实标准。
